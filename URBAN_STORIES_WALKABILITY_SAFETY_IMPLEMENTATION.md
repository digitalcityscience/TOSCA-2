### Exact analytical definitions and NULL semantics

- **`comfort_score`**: Modelled, not measured. Pedestrian comfort 0-100: weighted mean of the components that have a value (weights surface 0.2, slope 0.2, lighting 0.15, shade 0.1, street 0.25, crossing 0.1; design choice, config/scoring/comfort.yml); steps capped at 35. NULL = comfort_null_reason. **NULL:** NULL = not scored (comfort_null_reason = insufficient_components); NOT zero comfort
- **`has_sidewalk`**: Sidewalk along a carriageway from OSM sidewalk=*; separate = mapped as its own way; not_applicable = the segment is itself a pedestrian way. NULL = not tagged. **NULL:** NULL = no sidewalk tag (has_sidewalk_source = missing); 'not_applicable' is a value for pedestrian ways, not NULL
- **`slope_dem_abs_mean_pct`**: Length-weighted mean absolute grade over <=10 m pieces. **NULL:** NULL exactly where slope_dem_pct is NULL
- **`comfort_shade`**: Modelled, not measured. Shade proxy from street-tree density within 30 m per hectare of the segment corridor (saturates at 40 trees/ha), raised to an ALKIS land-use floor in forest/copse/cemetery. A proxy for canopy, not measured shade; tunnels not applicable; NULL outside the tree cadastre (Hamburg only). Weight 0.1. **NULL:** NULL outside the tree cadastre (Hamburg only) or tunnels (not applicable); component dropped
- **`safety_index`**: Modelled crash-concentration index, 0-100 (higher = lower modelled concentration): 100 * 2^(-accident_rate_smoothed / 8). This is not exposure-adjusted risk. NULL outside Hamburg accident coverage. **NULL:** NULL = no safety score (outside Hamburg accident coverage); NOT zero safety and NOT a safe segment
- **`n_accidents_ped_5y`**: Destatis Unfallatlas accidents in the five selected non-pandemic years (2019, 2022-2025) with IstFuss=1, assigned once to this segment within 30 m. Count, not an exposure-adjusted risk. **NULL:** never NULL (contract nullable: false)
- **`n_accidents_bike_5y`**: Destatis Unfallatlas accidents in the five selected non-pandemic years (2019, 2022-2025) with IstRad=1, assigned once to this segment within 30 m. Count, not an exposure-adjusted risk. **NULL:** never NULL (contract nullable: false)
- **`accident_rate_smoothed`**: Modelled, not measured. Gamma-Poisson empirical-Bayes vulnerable-road-user accident rate per km over the selected five non-pandemic years: (count + Hamburg-wide rate * 0.25 km) / (length + 0.25 km). NULL outside Hamburg accident coverage. **NULL:** NULL outside Hamburg accident coverage (safety_null_reason = outside_accident_coverage); NOT zero accidents
- **`comfort_class`**: comfort_score class: very_low < 20 <= low < 40 <= moderate < 60 <= good < 80 <= very_good. NULL when not scored. **NULL:** NULL exactly where comfort_score is NULL
- **`comfort_slope`**: Modelled, not measured. Slope comfort from the DEM grade (slope_dem_abs_mean_pct), piecewise linear: 0 % = 100, 6 % = 60 (DIN 18040 ramp limit), 15 % = 0. NULL = no DEM slope (bridge/tunnel, < 5 m, outside DEM) or steps (not applicable). Weight 0.2. **NULL:** NULL = no DEM slope or steps (not applicable); component dropped
- **`comfort_surface`**: Modelled, not measured. Surface comfort from OSM surface=* (asphalt/concrete best, soft or rough worst; table in config/scoring/comfort.yml). NULL = surface unknown or value not in the table. Weight 0.2. **NULL:** NULL = surface unknown or value not in the scoring table; component dropped (comfort_surface_basis = missing)
- **`comfort_lighting`**: Modelled, not measured. Lighting comfort from OSM lit=* (lit 100, limited/partial 60, unlit 20). NULL = lit unknown (also when the tag is not understood). Weight 0.15. **NULL:** NULL = lit unknown or tag not understood; component dropped
- **`comfort_crossing`**: Modelled, not measured. Crossing comfort by OSM crossing=* type (signals/zebra best, unmarked/informal worst). Only for crossing segments; all other segments not applicable. Weight 0.1. **NULL:** NULL for every segment that is not a crossing (not applicable)
- **`comfort_street`**: Modelled, not measured. Street environment: pedestrian ways by class (pedestrian > footway > path > track), minus a penalty when next to a busy road; carriageways by speed and sidewalk presence (tagged, or inferred from a parallel mapped footway). Crossings not applicable. Weight 0.25. **NULL:** NULL for crossings (not applicable) or when no street-environment input exists; component dropped
- **`safety_index_400m`**: Modelled, not measured. Length-weighted safety_index of walking-network segments reachable within 400 m from the existing building origin (connector included). Higher = lower modelled recorded-crash concentration. NULL for no origin (see score_null_reason) or safety_null_reason_400m. **NULL:** NULL when the building has no main-network origin (origin_quality = none; reason in score_null_reason), or when the *_null_reason_400m column gives the reason (connector longer than 400 m, or nothing scored within the radius)
- **`comfort_mean_400m`**: Modelled, not measured. Mean pedestrian comfort (walk_segments comfort_score, 0-100) of the street network within 400 m of walking distance from the building origin (connector included), weighted by the length of each segment inside the radius; unscored segments are left out (TICKET-02, D-011). NULL = see score_null_reason (no origin) or comfort_null_reason_400m. **NULL:** NULL when the building has no main-network origin (origin_quality = none; reason in score_null_reason), or when the *_null_reason_400m column gives the reason (connector longer than 400 m, or nothing scored within the radius)

## Local styling and interactions

- `styles/walkabilitySafety/metrics.ts`: 14 segment and 2 building metrics, labels, directions, classification bounds and palettes.
- `cartography.ts`: type-safe expressions and scale-dependent line widths. `index.ts`: native MapLibre casing/thematic street passes, building fill/outline, popup definitions. `legends.ts`: exact legend classes generated from the same scales. Accident indicators use segment geometry; no invented or overlapping point layer.
- Comfort palette: `#ad472b #d88a39 #c5bd83 #42978b #00695c`; safety: `#922b57 #ce6580 #c9b4cf #688cbd #244c83`; shade: `#e4d7b5 #bdd2bd #7cb5ad #398b91 #085a70`; slope: `#ffffb2 #fecc5c #fd8d3c #e34a33 #8c1745`; counts: `#dce5ed #b6a6cf #9273b3 #704498 #42145f`; rate: `#eee4f0 #ceb5d8 #aa7abc #803e99 #501267`. No data: `#858b94`. Sidewalk colors and class labels are in `metrics.ts`.
- Streets begin at zoom 9. At city scale the network is deliberately thin and partly transparent (0.8 px at z9, 1.25 at z11, 2 at z13); it becomes 3.6 px at z15, 5 at z16, 8 at z18 and 12 at z20. A dark slate casing adds 1.7 px; no white casing or lowest class is used, so streets remain visible over light basemaps. Round caps and joins keep close-scale paths clear. Selection turns the casing yellow without replacing the thematic color. Buildings retain zoom floor 14 and 0.8 fill opacity. MapStore puts street passes above the building passes. No administrative fills obscure the network.
- Five chapters: comfort → sidewalks/slope/shade → safety → selected building → exploration. Text uses plain sentences that say what colour, click and selector do. Metric changes themselves preserve camera, opacity, visibility and filters via `setStandaloneLayerStyle`. Active metrics and legends follow runtime layer records, including layer deletion/re-addition.
- Both chapter playback and Explore expose the existing metric selector and layer settings (attribute filters, visibility, opacity). No new layer registry or map engine. Frontend probe caches and runtime lookup separate distinct local story entries sharing the same building data, so a Walkability layer cannot borrow 15-Minute City styling.
- Street clicks use the existing popup query/deduplication infrastructure. In the building chapter, a building click instead opens a clear card in the Urban Stories side panel with nearby walking safety, comfort, covered street length and available-data share; the selected building gets a yellow outline. Missing MVT metric keys explicitly show no data; optional absent context fields are omitted; zero remains zero.
- Selection uses feature state on existing sources and persists across compatible metric style changes. Closing the popup clears it; removing the source first is safe. There is no invented catchment geometry, probability, accident point layer, or exposure normalization.

## Remaining limits

A sampled tile does not verify every area. There is no published raw accident point layer in this story's contract; accident options visualize segment counts/rate only. MVT omits NULLs, so a missing metric key cannot alone distinguish NULL from a delivery omission; catalog schema checks and source NULL descriptions provide context. The local export records data-origin gaps (for example DGM1 source checksum and a third-party Unfallatlas merged copy); this UI does not resolve them. Grade and tree data have substantial missing coverage. Comfort includes inferred inputs, with confidence and basis available in inspection. The safety index is a model of recorded crashes, not pedestrian exposure or individual injury risk.
